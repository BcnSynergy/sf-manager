# Demo instance on the production VPS

Objective: run a public demo with fictitious data at `sfmanager.demo.bcnsynergy.com` next to production on the same VPS, and deploy either one at will. Delivery: `stacked-to-main`, branches `demo-instance/<NN>-<slug>`, one PR per phase, phase 2 in two (forecast about 2000 authored lines in 5 PRs). Runners: Jest in `apps/api` (`npm test`, `npm run test:integration`), Vitest in `apps/web`, shell tests in `deploy/test-*.sh`, `deploy/smoke-test.sh` (CI), `npm run format:check`.
